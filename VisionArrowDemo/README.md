# VisionArrowDemo

这是研究文档对应的 visionOS 首版原型。打开 `VisionArrowDemo.xcodeproj`，选择 Vision Pro 真机，设置自己的开发团队和 Bundle Identifier，再运行。首次使用时在窗口打开混合沉浸空间；标记面板会常驻在视野右下方、正前方约 55 厘米处，可用手指直接触碰按钮，也可用注视加捏合操作。沿安全的 L 形路线依次记录起点、至少一个转弯点和终点，返回起点后开始导航。

实现范围：ARKit 世界追踪和 `WorldAnchor`、路点撤销与清空、地面平面检测、贴近地面的空间箭头、返回起点检查、按顺序推进路段，以及设备或路点追踪丢失时暂停提示。箭头由简单几何体组成，无需外部模型。首次打开沉浸空间时，请允许世界感知权限。识别到地面后，箭头默认位于地面上方约 1 厘米；尚未识别到地面的路段暂不显示箭头。

这个原型不做避障、自动寻路或跨启动恢复。地面检测以 ARKit 识别的水平地面平面为准，台阶、坡道和未识别区域可能没有箭头；箭头也不表示前方可安全通行。真机上仍需校准离地间隙、箭头间距、到达阈值与面板位置；请只在安全且平坦的室内区域试走。ARKit 数据提供器在模拟器中不可用，模拟器仅适合检查静态界面。正常点击“结束演示并关闭空间”时，程序会先清理本次路线的锚点。

当前地面检测版本（构建号 3）已安装到 Vision Pro 真机；地面识别、箭头高度和覆盖范围仍需在头显中试走验证。
